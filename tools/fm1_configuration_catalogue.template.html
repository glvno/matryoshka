Which FM-1 profiles belong in the bank?

This catalogue contains configurations with Include, Needs more testing or Exclude recommendations—not a new bank, an audition approval, or an importable patch file.

Snapshot: 12 November 2026. “Current” means the tested prototype firmware cf98f108…. Older measurements stay older; a clean partial run does not qualify untested phases.

Groups and configurations rank Include → Needs more testing → Exclude; equal-ranked groups are alphabetical. Within a recommendation, profiles at original polyphony parity prioritize more FX before extra voices.

How to interpret voices, effects and evidence

Include means candidate-pool advice, not “put every alternative instrument in the bank.” No current selection is changed by this report.

Voices: auxiliary one-voice control groups do not add played notes. Shared-filter profiles retain independent amplitude envelopes; shared-amplitude and shared-contour profiles explicitly couple envelopes. Original-synth polyphony is a hardware reference, not the FM-1 source patch’s allocator count.

Effects: total effects include the intrinsic/native effects already exposed by the instrument. “No added FX” does not remove native Chorus, Drive/timbre or Reverb. The word native here means intrinsic effect, not wire-format support.

Evidence: first-render peaks are retained. A stopped run leaves later phases unknown; zero guards cover only observed phases. The standard95% headroom target remains. Only the five requested retests use the disclosed interpretation: complete five-second matrices below100% with zero mute, shedding or observed late halves. Those exceeding95% are explicitly labeled reduced-headroom acceptances, not standard95% passes. Earlier failures remain in history. Older-only peaks are not current CPU predictions.

Scope: rejected, failed, unmeasured and unresolved configurations remain visible. Only older measured entries covered by a final current-firmware complete pass on the same or a dominating configuration are removed: at least the same played notes and added effects, the same intrinsic effects, no additional articulation coupling or DSP compromises. Every removal has a replacement ID and both evidence records in the JSON’s supersededConfigurations. Current failures and unknown equivalence are not hidden.

Polyphony versus FX: once the original synth’s played-note count is reached, prioritize the fullest FX rack possible. Extra polyphony with an incomplete Drive + Chorus + Delay + Reverb rack is Exclude, even if it passes CPU testing. Extra voices are eligible only after the full rack is present. Intrinsic effects count; protected drum/drone sources are unchanged.
