# Shush 101: its factory presets, one block per preset (web/src/preset-cards.ts; npm run presets -- check).
# "preset: NAME" starts one (up to 24 characters; the FM-1 shows 16). Under it, one row per line: "row = value".
# A row not listed keeps Init's value. A row is "section / label", or the label alone when no other row has it.
# A number is in the row's unit; a choice row takes a name; a switch takes on or off. Init and the ranges:
# The level row (controller / volume) the loudness step sets in every preset (#448): leave it to it.
#
# modulator
#   rate = 3 Hz                        0.02..40 Hz
#   waveform = TRIANGLE                TRIANGLE, SQUARE, RANDOM, NOISE
#   mod sync = on                      off, on
#   division = 1/16                    1/16T, 1/16, 1/8T, 1/16., 1/8, 1/8., 1/4, 3/8, 1/2, 5/8, 1/1
# vco
#   vco mod = 0                        -4..4
#   range = 8'                         16', 8', 4', 2'
#   pw = 0                             -4..4
#   pwm source = MAN                   ENV, MAN, LFO
#   tune = 0 ct                        -100..100 ct
# source mixer
#   pulse = 0                          0..1
#   saw = 0.6                          0..1
#   sub osc = 0.35                     0..1
#   sub mode = 1 OCT DOWN              1 OCT DOWN, 2 OCT DOWN, 2 OCT PULSE
#   noise = 0                          0..1
# vcf
#   freq = 500 Hz                      20..16000 Hz
#   res = 0.35                         0..1
#   env = 3                            -4..4
#   mod = 0                            -4..4
#   kybd = 0.5                         -4..4
# env
#   vca = ENV                          ENV, GATE
#   trigger = GATE+TRIG                GATE+TRIG, GATE, LFO
#   attack = 0.003 s                   0.001..5 s
#   decay = 0.25 s                     0.001..5 s
#   sustain = 0.4                      0..1
#   release = 0.1 s                    0.001..8 s
# controller
#   portamento = 0.15 s                0.001..5 s
#   porta mode = OFF                   ON, OFF, AUTO
#   bend vco = 0.17                    0..1
#   bend vcf = 0                       -4..4
#   lfo mod = 0.1                      0..2
#   volume = 1.29                      0..2

# Classic SH-101 roles (#869), set from the panel. Units: vco mod, env, mod, kybd and the bend rows in octaves (kybd 1 =
# the whole key); pw 0 = 50 %, 1 = 5 %. The envelope's `long` setting plays decay and release 2.4 times the row's value.
# BEND VCO is the lever's whole pitch bend (#976), 0 to 1 octave as the SH-101's; Init's 0.17 is the 2 semitones every
# preset bent before, so each keeps its bend. ENV TRIGGER sets the note priority as the SH-101's does: GATE+TRIG the last
# key held, GATE and LFO the lowest.
# MOD SYNC on (TEMPO) runs the modulator, and with it the arpeggiator, at DIVISION on the FM-1's tempo (#956); off (FREE) at
# RATE. A preset's division is a musical one near its rate at 120 bpm, so its vibrato or sweep keeps its feel. Wind stays
# FREE: its 0.2 Hz sweep is slower than the longest division (1/1, 0.5 Hz at 120 bpm).
engine: Shush 101
