# Hera 6: its factory presets, one block per preset (web/src/preset-cards.ts; npm run presets -- check).
# "preset: NAME" starts one (up to 24 characters; the FM-1 shows 16). Under it, one row per line: "row = value".
# A row not listed keeps Init's value. A row is "section / label", or the label alone when no other row has it.
# A number is in the row's unit; a choice row takes a name; a switch takes on or off. Init and the ranges:
#
# voice
#   voices = 6                         1..16
# lfo
#   lfo rate = 3 Hz                    0.02..40 Hz
#   lfo → pitch = 0                    -4..4
#   pwm = 0.3                          -4..4
#   lfo → filter = 0                   -4..4
# dco
#   wave = saw                         sine, triangle, saw, square, sharktooth, reverse saw
#   pw = 0.5                           0.05..0.95
#   sub = 0.25                         0..1
#   noise = 0                          0..1
# filters
#   hpf = 20 Hz                        20..16000 Hz
#   cutoff = 1400 Hz                   20..16000 Hz
#   res = 0.15                         0..1
#   env = 2.2 oct                      0..4 oct
#   kybd = on                          off, on
# env
#   envelope: a screen, not a value
#   a = 0.01 s                         0.001..5 s
#   d = 0.8 s                          0.001..5 s
#   s = 0.6                            0..1
#   r = 0.5 s                          0.001..8 s
#   vca = 1                            0..2
# chorus
#   chorus rate = 0.5 Hz               0.05..5 Hz
#   chorus depth = 0.55                0..1
#   chorus mix = 0.5                   0..1
#   out: a screen, not a value
#
