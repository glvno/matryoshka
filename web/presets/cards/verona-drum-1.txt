# Sounds follow the Vermona DRM1 MKIV manual's channel recipes. These are model studies, not measured hardware matches.
# The rows follow the original's knobs: see web/scripts/verona-voices.ts for what each does here.
# pitch (kick, drum 1, drum 2): 0..1 over the original knob's range, the kick 22..380 Hz, drum 1 18..300 Hz, drum 2
# 24..430 Hz. bend: 0 none, up a falling sweep, below 0 a rising one; the kick's only falls, 0..1 up to four octaves. time:
# the kick's pitch sweep. kick / attack: the spike's shape, 0 a 3 ms click, up a tail that widens it into a push. fm int:
# 0 off, up to four octaves either way. wave: 1 a sine, up to an overdriven square. clap: the claps' rate, so their number
# (below about 22 Hz one clap). pitch 2 / pitch 3: octaves below the multi's pitch, off at -4. A hi-hat's row plays it
# open or closed by its trig switch; the HH 1 CL and HH 2 CL rows (G4, A4) play it closed whatever trig says.
