# Project

IDs: D-050–D-099

Matryoshka is a standalone **hard fork** of Modular-1, owned and decided by michael glaviano, and its work is tracked in GitHub issues on glvno/matryoshka, never upstream. The whole repository is GPL-3.0-only: it has no FM engine and no Felucca features, and it reuses only Felucca's flashing path and hardware layer, whose files keep their headers. The software is called Matryoshka wherever users see a name, and development happens on macOS only. In user-visible text a stored sound is a **patch**, a **preset** is one assembly device's stored card values, "**voices**" means polyphony and "**engine**" means an engine assembly. The About card holds the owner's words, the **Slop Disclosure**, the credits and the funding links, and the site counts visits with cookieless Cloudflare Web Analytics and loads no other trackers.
