# Device UI

IDs: D-200–D-249

The FM-1 is a patch player: patches are built in the browser, and the device plays them through one firmware build that runs one patch at a time. Every top-level module or assembly with card rows is a **device**, and Main, the Steps tracks and the Output are devices too, all in one **grouped order**. A device's card rows become **pages** of four, and K1..K4 are **edit bindings** to the page in focus. Navigation follows one rule: HOME goes back along a **trail**, ALGO moves sideways, SELECT picks, and PRESET only changes patches. GLO, SEL and ENV are **fixed buttons** (GLO opens the FM-1's own settings page, ENV the **environment** page of devices and their presets), while FX, LFO, EDIT and ARP stay patch buttons, each with a **button kind**. The settings menu, the device page layout, the patch toast, the SELECT and ALGO cards, the LCD manual rules and the **panel core** complete the panel.
