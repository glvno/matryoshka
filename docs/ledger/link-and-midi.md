# Editor link and MIDI

IDs: D-450–D-499

The editor and the FM-1 talk over a SysEx protocol on USB MIDI, and new capabilities are announced by INFO feature bits. Connecting the FM-1 offers **Live** sync as the default, and one switch turns it on or off. Under Live the editor holds the FM-1's PRESET and program change, pauses while its patch is over budget, and gets knob turns as exact values; presets move with their own messages. The FM-1 reports which **slot** it plays, listens for MIDI on one channel (omni by default), loads bank slot n on program change n, and sends every panel control raw on MIDI out per a documented map. **Voicing** channel ranges make the FM-1 multitimbral over MIDI, and the web app can follow an FM-1 running any firmware through plain MIDI and a **MIDI profile**. The FM-1 is also a USB audio recording device, TRS and USB MIDI input are kept apart, and MIDI input is ignored while firmware is being installed.
