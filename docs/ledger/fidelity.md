# Factory fidelity

IDs: D-700–D-749

Factory cards follow their original instruments' controls ([D-347](patches-and-presets.md#D-347)). This file records choices about how those controls and patch points work. It does not certify that an instrument is complete. The full release scope and architectural and interface parity target follow [D-132](releases.md#D-132).

| ID | Decision | Status | Date | Source |
|---|---|---|---|---|
| <a id="D-700"></a>D-700 | Canvas XL exposes its control sources as assembly output jacks, including four independent random voltages, the inverter and preset voltage. Each patch-field input has a PATCH choice that accepts a cord at its assembly input. Its other seven choices are shortcuts to the main pitch, pressure, sequencer, envelope, pulser, first random voltage and modulation oscillator. | Decided | 2026-10-26 | michael glaviano, ruled in the 1.5 review page 2026-10-27; issue #303; Music Easel manual audit |
| <a id="D-701"></a>D-701 | Silver Box has a named SAW / SQUARE waveform switch. The copy inside the `<7PH` test patch keeps a plain oscillator waveform row to fit its byte budget. | Decided | 2026-10-26 | michael glaviano, ruled in the 1.5 review page 2026-10-27; issue #303; factory integration handoff |
| <a id="D-702"></a>D-702 | Silver Box's TUNING row spans the Roland TB-303's ±500 cents and no more. The row is a Macro from 0 to 1, with 0.5 in the middle playing no detune. An Attenuverter turns it into ±5 semitones on the oscillator's pitch. The copy inside the `<7PH` test patch keeps the oscillator's fine tune (±100 cents) and the short `cutoff` row name, to fit its byte budget. | Decided | 2026-10-27 | michael glaviano, in chat 2026-10-27; issue #375; [TB-303 owner's manual, specifications](https://archive.org/details/synthmanual-roland-tb-303-owners-manual); `web/scripts/gen-assemblies.ts`; `web/scripts/gen-presets.ts` |
| <a id="D-703"></a>D-703 | Io 4 on the FM-1 names the positions of its switches with the Roland Jupiter-4's panel legends, except its five OFF / ON switches: sub, noise, portamento, hold and ensemble. Those stay numbered, 1 for OFF and 2 for ON, because the FM-1 patch has 2 bytes left. For the same reason, NOISE shares the VCO's second page, POLARITY reads NORM / INV and TRANSPOSE reads NORMAL / -1 OCT. | Decided | 2026-10-27 | michael glaviano, ruled in the 1.5 review page 2026-10-27; issue #375; Jupiter-4 owner's manual ('82 AUG.), specifications; `web/scripts/gen-assemblies.ts` |
| <a id="D-704"></a>D-704 | Io 4's LFO RATE uses the LFO's fast range: the `rate` row times two, 0.04 to 80 hertz, so it reaches the Jupiter-4's 80 hertz. The row shows the rate the LFO runs at ([D-372](engine.md#D-372)). It reaches below the Jupiter-4's 0.1 hertz, down to 0.04 hertz. The wide range of [D-445](modules.md#D-445) stays at 55 hertz for Algo Four XL, whose DX100 LFO tops out there. LFO BEND reaches 1 or 4 octaves of the fast range, as NORM / WIDE selects. | Decided | 2026-10-27 | michael glaviano, in chat 2026-10-27; issue #375; issue #351; Jupiter-4 owner's manual ('82 AUG.), specifications; `web/scripts/gen-assemblies.ts` |
| <a id="D-705"></a>D-705 | Silver Box ships four demo [**patterns**](vocabulary.md#pattern) in the Roland TB-303's style, numbers 2 to 5, all in short note words, the last in the 303's triplet mode (12 steps of 1/16T), and one [**song**](vocabulary.md#song) of 8 entries that chains them with shifts. Its pattern 1 stays empty and the song is not selected, so the keys still play it as a synth and PLAY alone plays nothing. The editor names its patterns as the 303 does, I-A1 to IV-B8; the FM-1 shows P01 to P64. | Decided | 2026-10-27 | michael glaviano, ruled in the 1.5 review page 2026-10-27; issue #375; `web/scripts/gen-presets.ts` |
