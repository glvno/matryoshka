# Factory fidelity

IDs: D-700–D-749

Factory cards follow their original instruments' controls ([D-347](patches-and-presets.md#D-347)). This file records choices about how those controls and patch points work. It does not certify that an instrument is complete. The full release scope and architectural and interface parity target follow [D-132](releases.md#D-132).
