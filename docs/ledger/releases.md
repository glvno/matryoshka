# Releases

IDs: D-100–D-149

The web editor and the FM-1 firmware are released together under one version, tagged `vX.Y.Z`; what each Semantic Versioning (SemVer) level means is proposed. A **release package** is built by hand with `release.yml`, passes `emu:smoke` and the owner's check on a real FM-1, is bundled into the app with its **sidecar**, and only then is tagged and published as a GitHub release. Version strings change only at a release, and between releases `main` carries the next minor's `-dev` version. The site on Cloudflare Pages serves only the newest release tag and builds no firmware, so a change reaches users only through a release, and the old GitHub Pages address serves only a **forwarder**. Every user-visible change adds a line to `CHANGELOG.md`; the firmware is built only in CI, that build is a required check only for pull requests that change firmware, the emulator smoke test and the scripted editor-link checks run locally on every firmware pull request before it merges, and Claude may merge its own pull requests.
