# Releases

IDs: D-100–D-149, D-1150–D-1199

The web editor and the FM-1 firmware are released together under one version, tagged `vX.Y.Z`; what each Semantic Versioning (SemVer) level means is proposed. A **release package** is built by hand with `release.yml`, and follows the final-artifact process in [D-146](#D-146). It satisfies the checks in [D-105](#D-105), is bundled into the app with its **sidecar**, and only then is tagged and published as a GitHub release. Version strings change only at a release, and between releases `main` carries the next minor's `-dev` version. The site on Cloudflare Pages serves only the newest release tag and builds no firmware, so a change reaches users only through a release, and the old GitHub Pages address serves only a **forwarder**. Every user-visible change adds a line to `CHANGELOG.md`; the firmware is built only in continuous integration (CI), that build is a required check only for pull requests that change firmware, and Claude may merge its own pull requests. Branch roles follow [D-145](#D-145), and release-candidate qualification follows [D-144](#D-144) (Decided). The rig's installation gate and the changes that need hardware checks are separate ([D-123](#D-123), [D-141](#D-141), Decided).
