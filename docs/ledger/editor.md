# Editor

IDs: D-550–D-649

The web editor is a canvas of cards: Main lives in the **Main dock** under it, and assemblies **expand** into frames and **collapse** back. Cards follow the "Edge" design: a choice is a **selector**, a cable dropped on a slider **thumb** routes to a parameter (there are no p1 / p2 jacks), and every edit is one undo step. A solid cable is one the user made, and a dashed **virtual cable** is something the app shows. The FM-1's limits appear as a **budget meter**, not as limits, and a switch over the canvas moves between the Patch view, the **FM-1 view** (the real firmware UI built as WebAssembly) and the **Flash view**. Patches stay in the browser and travel as **share links**, and only a link too long for a URL becomes a **stored link** on the site. Phones are not a target platform, but a patch can be opened, played and edited on one.
