# Process

IDs: D-001–D-049

How this ledger works. Every rule about the ledger is a row here, so the rules change the same way anything else does: by amending or superseding a row in a pull request. michael glaviano is the decider for this file. The readable rendering of these rows is [README.md](README.md); when the two disagree, the row wins and the README is fixed.
