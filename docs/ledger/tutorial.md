# Tutorial

IDs: D-650–D-699

The tutorial is a **course** kept as data in `web/src/tutorial/course.json`. It is edited only in the dev-server **lesson editor**, which validates the course before it saves and never commits or publishes. Learner progress follows permanent step ids, and chapters are published one by one. Each chapter loads its own starting patch after keeping the learner's open patch as a **variation**. There is no "do it for me": **task steps** wait for Continue, and their **requirements** are check boxes placed in the step text, each on its own line. The tutorial is offered on every visit until the learner opts out, and a separate **tour** serves experienced users. Sound starts only from playback clicks and carries on between steps. There is no Riff button: playback is a held Note, and a **riff** a step still stores is data only ([D-663](tutorial.md#D-663)). The course uses no A/B events.
