# Patches and presets

IDs: D-300–D-349, D-850–D-899

The **factory patches** are Matryoshka's own, generated from the **factory assemblies** with Oracle V first, then the 808 and 909 Kits and `<7PH`, with new ones added at the end, each fitting the FM-1 and named in house style after the instrument it recalls. An instrument cut down to fit can also ship whole as an [**XL**](vocabulary.md#xl), a factory patch of the browser only that never reaches the FM-1. An **engine** is derived from what an assembly holds (keys reach a **Voicing** module or a **Drum map**, and audio comes out); engines sit on their own shelf and are wired in when inserted. A **preset** is a stored set of **card row** values for one **structure**, loadable by any assembly device of that structure: factory engines ship read-only presets, and the editor and the FM-1 each keep a preset store and move presets only on request or under Live. On the FM-1 the **bank** is the only patch list: SAVE writes the running patch to its slot, ENV held + SAVE stores only the focused device's preset, choosing a patch never writes flash, and the first boot or FACTORY RESET writes the factory patches. In the browser the user's own patches live in **Your patches**, a curated **Community shelf** ships with the app, and a first run opens Vernon 100.
