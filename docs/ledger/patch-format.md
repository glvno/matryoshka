# Patch format

IDs: D-250–D-299, D-1000–D-1049

A patch exists as editor JSON and as the compact binary the FM-1 plays. Format 55 carries optional master FX bindings and selects verified LFO/Harmony enabled-state lights ([D-1010](#D-1010)); patches using neither retain their lowest compatible format under [D-281](#D-281). Module type and port indices are append-only, and format changes update the editor, both engines, presets and tests together ([D-250](#D-250), [D-252](#D-252)). Firmware reads formats 31 through 59 and plays the fallback patch for a slot it cannot load ([D-251](#D-251), [D-1010](#D-1010)). Updates preserve saved slots rather than replacing factory matches ([D-887](patches-and-presets.md#D-887)); load-time format conversion remains distinct from a flash write ([D-266](#D-266)). Patch slots and settings remain separate from the user preset store ([D-264](#D-264)). Format 59 lets a patch refer to patterns in the FM-1's [**pattern store**](vocabulary.md#pattern-store) ([D-1015](#D-1015)), which takes 4 of the bank's sectors, so the bank has 60 slots ([D-1016](#D-1016), [D-1017](#D-1017)). The factory patches are stored packed ([D-1014](#D-1014)) in two images of one layout: the [**firmware tier**](vocabulary.md#firmware-tier), compiled in, and the [**factory region**](vocabulary.md#factory-region) in the 18 sectors 0xEA000 to 0xFBFFF, which also holds the factory engine presets and drum patterns ([D-1020](#D-1020)).
