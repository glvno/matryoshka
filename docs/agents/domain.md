# Domain documentation

Read README.md, docs/ARCHITECTURE.md and LICENSING.md. Tutorial behavior is specified in docs/TUTORIAL.md. User-visible complete sounds are patches; reusable nested building blocks are assemblies. Firmware is outside this tutorial work.
- **Engine** (#159, redefined 2026-10-22): an assembly that takes keys and makes audio (keys → voicing → voices); derived, no checkbox. See CONTEXT.md.
- **Glossary:** `CONTEXT.md` at the repo root (patch, engine, voicing, voice, key source, device, environment, arm, preset, ...).
