# Issue tracker

Use GitHub issues in **glvno/matryoshka** (`gh --repo glvno/matryoshka`). The `origin` remote is this project; `upstream` (WiggisModular/Modular-1, fetch only) is the repo it was hard-forked from on 2026-10-17. Never file issues upstream. Every change reaches `main` by pull request (since 2026-10-23); Claude may merge its own.

**Board:** the GitHub project "Matryoshka", https://github.com/users/glvno/projects/6 (linked to the repository). Its Status columns are Inbox (not triaged), Next, In progress, Device check (built and emulator-tested, waiting for a real FM-1), Someday (spikes and ideas) and Done; Priority is High, Medium or Low. A new issue goes on the board in Inbox (`gh project item-add 6 --owner glvno --url <issue url>`). An issue whose work starts moves to In progress, and one waiting for the owner's device check moves to Device check. The owner decides what moves out of Inbox.
