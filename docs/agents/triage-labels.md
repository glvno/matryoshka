# Triage labels

Use one category (`bug` or `enhancement`), `editor` for web tutorial work, and `ready-for-agent` for accepted implementation work ([D-051](../ledger/project.md#D-051)). Triage-generated issue bodies and comments start with `> *This was generated by AI during triage.*`.

Labels do not carry plan state ([D-069](../ledger/project.md#D-069)). Where an issue stands is its Status on the board, its planning order is its Horizon, and the release it is planned for is its milestone. See [issue-tracker.md](issue-tracker.md).
