# Triage labels

Use one category (`bug` or `enhancement`), `editor` for web tutorial work, and `ready-for-agent` for accepted implementation work. Triage-generated issue bodies and comments start with `> *This was generated by AI during triage.*`.

An open issue with no milestone takes one of two labels. `later` means it is planned, but not for the next two releases. `icebox` means it is kept as an idea, with no plan to do it. An issue with a milestone takes neither.
